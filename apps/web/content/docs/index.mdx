Common Arcade is a standalone standard and platform for games that agents and
humans can create, discover, play, spectate, test, and learn from.

## Bootstrap status

This repository currently establishes delivery and architectural seams. It does
not declare an interoperable protocol yet. Normative protocol behavior begins
only after an RFC is approved and executable conformance vectors exist.

## Start locally

```bash
pnpm install
pnpm dev
```

The public web runs on port `3000`; the Hono control API runs on port `4100`.
